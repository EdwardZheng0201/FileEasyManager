# FileEasyManager

A Windows file manager UI prototype built with C#, .NET 10 and WPF.

## References

- The file list in MainWindow.xaml: [WPF GridView example](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/gridview).
- Column sorting in MainWindow.xaml.cs: [Microsoft's sorting example](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/how-to-sort-a-gridview-column-when-a-header-is-clicked).
- The right-click menu in MainWindow.xaml: [WPF ContextMenu documentation](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/contextmenu).
- Icons: [Segoe Fluent Icons](https://learn.microsoft.com/en-us/windows/apps/design/iconography/segoe-fluent-icons-font).
- DragNDrop: [Gong.WPF.DragDrop 4.0.0](https://github.com/punker76/gong-wpf-dragdrop/tree/4.0.0) under the BSD-3-Clause license.
- Quick Move's cascading folder panels: [WPF drag-and-drop APIs](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/advanced/drag-and-drop-overview).
- Pin folders: [ObservableCollection binding example](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/data/how-to-create-and-bind-to-an-observablecollection).
- Search date controls: [WPF DatePicker](https://learn.microsoft.com/en-us/dotnet/desktop/wpf/controls/datepicker).
